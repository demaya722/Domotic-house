# Sistema Domòtic - Control de Casa Intel·ligent

## Descripció
Sistema de control domòtic per automatitzar funcions d'una llar amb l'objectiu de millorar el confort, seguretat i eficiència energètica.

## Mòduls a Implementar

### 1. Control d'Il·luminació
- Encendre/apagar llums per habitació individual o totes juntes
- 6 habitacions: sala d'estar, cuina, bany i 3 dormitoris
- Visualització de l'estat actual de totes les llums

### 2. Control de Temperatura
- Encendre/apagar sistema de climatització
- Establir temperatura desitjada
- Consultar estat del sistema

### 3. Control de Persianes
- Pujar i baixar persianes de l'habitació actual
- Control remot
- Consultar estat de les persianes

### 4. Control de Ventiladors
- Encendre/apagar ventilador de l'habitació actual
- Regular velocitat del ventilador
- Consultar estat del ventilador

## Objectiu
Simular un sistema domòtic complet que permeti als usuaris controlar manualment diferents aspectes de la seva llar mitjançant un menú d'opcions.

## Tecnologia
Implementat en Java/Python amb condicionals, excepcions i mètodes.
